The website allows users to browse a catalogue of 16 products across five categories — Electronics, Fashion, Books, Home, and Sports. All product cards are written in HTML with real product images, while JavaScript handles the interactive functionality of the site. Users can search for products by name using a live search bar, and filter them by category using filter buttons. Each product can be added to a shopping cart, where users can increase or decrease quantities, remove items, and view a running total with shipping calculated automatically in Ugandan Shillings (UGX). Cart data is saved using localStorage, meaning the cart persists even when the page is refreshed. The website also includes a checkout page with a form that collects the customer’s name, email address, phone number, and delivery address. All fields are validated using JavaScript before the order is submitted, including email format and phone number checks using regular expressions. The project demonstrates the use of core JavaScript concepts including DOM manipulation through methods such as document.getElementById(), document.querySelector(), createElement(), appendChild(), and addEventListener(). It also makes use of arrays and objects for storing product and cart data, localStorage for data persistence, and try/catch blocks for error handling throughout the application. The project is organised across three pages — index.html, cart.html, and checkout.html — with a shared stylesheet in css/style.css and all JavaScript logic contained in js/script.js.
